# Libchecker

Kho lưu trữ này chứa các **bài toán theo phong cách Library Checker**, được thiết kế để kiểm tra việc cài đặt các cấu trúc dữ liệu và thuật toán phổ biến trong **Competitive Programming**.

## Nội dung

Repository bao gồm nhiều bài toán thuộc các chủ đề khác nhau, chẳng hạn như:

- Segment Tree
- Wavelet Tree
- DSU Rollback
- Virtual Tree
- Geometry
- và nhiều cấu trúc dữ liệu / thuật toán khác

Mỗi bài toán trong repo thường đi kèm với đầy đủ các thành phần cần thiết:

- **Statement** (LaTeX / Polygon)
- **Generator** để sinh test
- **Validator** kiểm tra input hợp lệ
- **Checker** chấm output
- **Test cases**

## Mục tiêu

- Cung cấp các bài toán dùng để **kiểm tra độ đúng của implementation**
- Hỗ trợ **kiểm thử thư viện thuật toán**
- Phục vụ **luyện tập Competitive Programming**
